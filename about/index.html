I’m Muhammad Muneeb Ur Rehman, a security engineer passionate about understanding how systems can be attacked and how to defend them. My focus is AI/LLM security, web application and API security, and offensive security, supported by a strong Linux and systems foundation.

I hold the OSCP certification and bring an attacker’s perspective to security reviews: question assumptions, trace trust boundaries, validate weaknesses, and help turn findings into concrete fixes. I’m especially interested in secure application design, code review, identity and access controls, and the security of LLMs, RAG, and tool-using agents.

I earned my Information Technology degree at George Mason University. My infrastructure background gives me practical context for securing the systems behind applications, especially Linux hosts, services, permissions, logs, and production troubleshooting.
