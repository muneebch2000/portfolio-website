~/ network_securityNetwork securityExpand +

Assessment workflow

  1. Map assets, services, DNS, and traffic flows.
  2. Review segmentation and administrative access.
  3. Validate firewall behavior and inspect packet captures.

Useful outputs

  • Network diagrams and access matrices
  • Rule reviews and packet evidence
  • Prioritized hardening recommendations
~/ cloud_securityCloud securityExpand +

Assessment workflow

  1. Review effective permissions and identity trust.
  2. Inspect network exposure, workloads, and secrets handling.
  3. Assess infrastructure code and audit visibility.

Useful outputs

  • IAM review and trust-boundary map
  • Infrastructure configuration findings
  • Remediation and verification plan
~/ offensive_securityOffensive securityExpand +

Assessment workflow

  1. Define scope, permissions, and success criteria.
  2. Investigate inputs and validate findings in a lab.
  3. Explain impact and retest the proposed remediation.

Useful outputs

  • Reproducible technical evidence
  • Risk-based findings with remediation
  • Retest notes and remaining limitations
~/ threat_modelingThreat modelingExpand +

Assessment workflow

  1. Identify assets, actors, and security objectives.
  2. Trace data across components and trust boundaries.
  3. Develop abuse cases and prioritize mitigations.

Useful outputs

  • Data flow diagrams and attack trees
  • Threat register with control owners
  • Security requirements and test scenarios
